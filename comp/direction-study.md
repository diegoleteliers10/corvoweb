# CorvoWeb visual directions

## Audience and job

People on macOS, Windows, and Linux need to understand how Corvo helps with real desktop tasks, then find the build for their system. Each direction uses actual screenshots captured from Corvo v0.1.4. The demos show real app search, Search Files, calculator, and emoji search.

## Directions

### Task Field Guide

An editorial task guide organized around “find, act, return.” Each use case shows what to type, what Corvo shows, and a real screenshot. Dark Corvo surfaces anchor the page. A quiet light canvas gives the instructions room. A platform strip leads to downloads.

### Palette Atlas

A map of the palette's real entry points. App search, files, clipboard, emojis, and system tasks appear as a connected index. The selected task opens a large real screenshot. Platform differences sit beside each relevant task.

### Desktop Field Notes

A compact product journal with a broad typographic headline, numbered real workflows, and a screenshot rail. It leads with the native app and open-source nature, then moves through practical examples and platform downloads.

## Material carried into the lead

- From the event-display challenger: keep one selected workflow in focus and label each visible part. Use the real interface as evidence.
- From the one-bit desktop challenger: make each interaction state legible and navigable. Keep Corvo's real dark UI and green selection color.
- From the broadside challenger: use a strong headline and readable editorial hierarchy. Keep the copy direct and factual.
- From the magazine-spread challenger: show several real ways to use Corvo in one glance. Keep the page spacious enough to read.
- From the clay-tower challenger: order tasks from simple to advanced. Keep the workflow sequence visible.
- From the folded-paper challenger: connect each instruction to its real result. Show input and output together.

## Raise to the assigned direction

- Real workflow proof: show the exact query and result in each task, with the corresponding real Corvo screenshot.
- Platform truth: identify OS-specific features at the task level and keep download choices available throughout.

## Evidence limits

- Captures come from Corvo v0.1.4 on macOS.
- Search Files appears as a command in the launcher. The app did not stay responsive after opening it during capture, so the comp does not claim a verified file-list result.
- Do not use the clipboard-history capture. It exposed private clipboard contents.
- Do not claim equal feature support across macOS, Windows, and Linux. State support only after checking the code and release artifacts.
